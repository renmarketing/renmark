### Task 2: loop.py driver (the core)
- **mode:** A
- **target:** renmark/loop.py
- **complexity:** hard
- **executor:** opus
- **parallel_group:** 2
- **est_tokens:** 2800
- **est_cost_usd:** 0.19
- **verifier:** python3 -c "import renmark.loop; print('ok')" && ruff check renmark/loop.py && mypy renmark/loop.py
- **serves:** REQ-11
- **spec:**
  Create renmark/loop.py — the deterministic loop driver. READ FIRST: the spec
  (.renmark/specs/2026-06-09-loop-mode.spec.md), renmark/state.py (usage_by_run_id from
  Task 1; pipeline state), renmark/summary.py (read_metadata/emit_pointer; SubagentOutput
  shape to mirror), renmark/lifecycle.py + renmark/sizing.py (never-raise + tunable-const
  style to mirror). Implement:
  - `loop.json` schema + read/write under `.renmark/loops/<id>/` (id = `loop-<date>-<slug>`;
    fields: goal, verify_cmd, budget_tokens, budget_usd_estimate, spent_tokens, run_id,
    max_iterations, iteration, status (running|done|budget-hit|max-iter|awaiting-approval|stalled),
    pending_step). Write before each iteration so a crash is resumable.
  - A budget parser accepting BOTH a token int and a `$` amount (convert `$`→tokens via a
    cost-per-kT constant / the plan cost model); store tokens + a `$` estimate.
  - `decision` builder: from a verify `.verification.md` (read_metadata → PASS/FAIL +
    summary) + the ledger spend delta (usage_by_run_id), produce a SubagentOutput-shaped
    dict `{goal_reached, evidence, next_action, model_recommendation, estimated_next_cost}`.
    Reads ONLY metadata + ledger — NEVER source/diffs/full bodies.
  - `stop_reason(state) -> str|None`: goal_reached (verify PASS) | spent>=budget |
    iteration>=max_iterations | approval-pending | empty next_action → maps to a terminal status.
  - Tunable constants: DEFAULT_MAX_ITERATIONS=5, DEFAULT_BUDGET_TOKENS=300_000.
  - NEVER raises into the caller; any read/parse failure → a terminal STOP status, not a crash.
  Type-annotated; stdlib + existing renmark modules only; no new dep. (The SKILL drives the
  actual orchestrate/verify invocations; loop.py owns the state machine + decision + stops.)
