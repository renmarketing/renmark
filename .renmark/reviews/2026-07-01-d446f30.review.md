# P8 behavioral skill testing — codex review (2a05fbf..HEAD)

**VERDICT 1 — Spec-compliance:** under-built — the deterministic lane never replays
current behavior; `renmark-execute --behavior --accept` cannot actually record
snapshots from the CLI; the two reference cases ship without any recorded snapshots.

**VERDICT 2 — Code-quality:** Critical 0, Major 3, Minor 1, Nit 0.

## Major
1. `renmark/behavior.py:224-280,348-355` — the deterministic "replay" never executes
   current behavior; it diffs two stored snapshots, and the judge path passes
   `actual=golden`. So the suite cannot detect regressions and the judge compares
   golden-to-golden. Fix: replay must produce a fresh current with-skill transcript
   (shadow-style current replay), compare it to the stored golden, and pass THAT as
   `actual` to the judge.
2. `renmark/cli/_engine.py:1061-1090` — `--behavior --accept` hard-wires a runner that
   always raises, so snapshot recording can never succeed from the documented CLI path.
   Fix: wire `--accept` to a real host-provided live runner, or reject the flag up front
   as unsupported until that runner exists, instead of pretending to capture.
3. `renmark/judge.py:150-169` — a malformed payload `{"outcome":"pass","confidence":"bogus"}`
   is treated as a validated PASS with confidence silently downgraded to `low` —
   violates "malformed responses never become a silent pass." Fix: any missing/unrecognized
   required field (`outcome`, `confidence`, `rationale`) → `validation_status="unvalidated"`
   with a non-pass outcome.

## Minor
4. `renmark/behavior.py:182-185,307-311` — `baseline_ref`/`golden_ref` interpolate directly
   into snapshot paths; a case file could use `../` to escape `tests/behavioral/**/snapshots`.
   Fix: validate refs as plain filename stems (no separators); reject resolved paths that
   escape the snapshots dir.

Orchestrator assessment: all three Majors independently confirmed valid. Major 3 is a
direct contract violation (silent pass); Major 1 questions the deterministic tier's core
value; Major 2 is the practical bootstrap blocker. Recommend a fix round before finish.
