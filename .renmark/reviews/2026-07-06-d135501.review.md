# Review: Agency Mode BL-0002 (HEAD~1..HEAD)

## Verdicts

**Spec: under-built** — the new AC11 behavior proof is not actually runnable because both new deterministic adapters fail when no writable system temp directory is available.

**Quality: Critical 0 | Major 2 | Minor 0 | Nit 0**

---

## Findings

### Major 1 — behavior.py: tempdir assumption brittle in restricted sandboxes

- **file:line**: `renmark/behavior.py:441`
- **severity**: Major
- **description**: `_render_skill_preamble_fresh()` and `_render_skill_preamble_agency_active()` call `tempfile.TemporaryDirectory()` which assumes a writable system temp dir. In sandboxed runners (e.g. codex `--sandbox read-only`) where `/tmp`, `/var/tmp`, `/usr/tmp` are unavailable, both adapters raise `FileNotFoundError`, causing the behavior runner to fail on the new AC11 cases.
- **fix**: Use a repo-owned writable directory (e.g. `repo / ".renmark" / "state" / "_behavior-tmp"`) with explicit `shutil.rmtree` cleanup in a `finally` block instead of `tempfile.TemporaryDirectory()`.

### Major 2 — _engine.py: activate/deactivate miss error handling

- **file:line**: `renmark/cli/_engine.py:1399` (approx)
- **severity**: Major
- **description**: `--activate-agency` and `--deactivate-agency` call `_agency.activate()` / `_agency.deactivate()` without catching `OSError` or `AgencyBloatError`. A write failure emits a raw traceback and exits non-zero without a stable error message, unlike adjacent `--set-mode` / `--clear-mode` which catch and format errors.
- **fix**: Mirror `--set-mode` / `--clear-mode` pattern: wrap in try/except, print a concise stderr message, return 1.
