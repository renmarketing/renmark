# Codex review — playwright-browser-control (main..HEAD, focus: default)

**Summary: Critical 1 · Major 6 · Minor 1 · Nit 0** (codex summary line said Major 5; enumerated list has 6).

## Critical
- **renmark/browser.py:44 — path traversal.** profile_path()/meta_path() accept raw names; a name with `/` or `..` escapes .renmark/state/browser-sessions, and `browser_cli forget` then unlink/rmtree's paths OUTSIDE the sessions dir. Fix: reject non-basename tokens (^[A-Za-z0-9._-]+$) and resolve-check every path stays under the sessions root before any read/write/delete.

## Major
- **browser.py:208 — is_stale() crash.** datetime.fromisoformat(data['saved_at']) can raise TypeError on non-string/naive values, uncaught → status/list/activate crash on bad metadata. Fix: catch TypeError too; treat missing/invalid/naive saved_at as stale.
- **browser.py:281 — activate() skips schema check.** A fresh-but-foreign/malformed JSON is copied to active.json and handed to Playwright MCP though validate_storage_state() exists. Fix: validate_storage_state(src) inside activate(), refuse on failure.
- **browser.py:30 — channel API inconsistency.** resolve_channel() accepts only playwright|mcp|auto, returns chrome-devtools on fallback, no native — violates the documented 3-channel contract; explicit chrome-devtools/native selection impossible. Fix: normalize one enum set across code+docs (playwright/chrome-devtools/native).
- **verify SKILL.md:247 — doc/code signature drift.** Examples call resolve_channel(repo, args) and activate(repo, profile=...) but real sigs are resolve_channel(override=None) and activate(name, repo_root=None) → copied code crashes. Fix: correct the skill examples to the real signatures/returns.
- **browser_cli.py:136 — login not graceful when chromium missing.** is_playwright_available() doesn't verify chromium.launch() succeeds and cmd_login() doesn't catch launch errors → not the documented remediation+exit path. Fix: real launch/close probe OR catch launch errors → remediation + non-zero.
- **browser.py:35 — cwd-relative session paths.** Paths default to Path.cwd() and the CLI never resolves/passes repo root → running from a subdir reads/writes the wrong sessions tree, breaking discovery/activation vs the repo .mcp.json. Fix: resolve repo root (nearest .git/.renmark) in the CLI and thread it through path helpers.

## Minor
- **tests/test_browser.py:146 — tests lock the wrong channel contract** ('mcp' vs documented names) and miss traversal-name + malformed-saved_at cases (which currently crash). Fix: add negative tests, align channel expectations to the intended public API.

## Cross-cutting theme
Task 3 (browser.py) and Task 6 (verify SKILL.md) drifted on the channel API: the skill documented a richer 3-channel contract (resolve_channel(repo,args) → playwright|chrome-devtools|native, activate(repo,profile=)) than the code built (resolve_channel(override) → playwright|mcp|chrome-devtools, activate(name,repo_root)). Reconcile to ONE contract.
