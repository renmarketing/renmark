## Verdict 2 — Code quality

Critical: 0 · Major: 2 · Minor: 0 · Nit: 0

1. **Major — `renmark/hygiene.py:92` + `:514`.** `version-unpacked` is
   registered `ephemeral, regenerable=True` but `budget_age_days=None`; the
   safe-deletion predicate filters to
   `s.budget_age_days is not None`, so `--artifact-hygiene --apply` can never
   automatically retire a *future* stale unpacked version tree through the
   registry-driven predicate — Task 1's one-time manual retirement worked,
   but there's no ongoing automated path for it. **Confirmed real** — not a
   false positive.
2. **Major — `renmark/hygiene.py:366` (`_all_dependency_refs`).** Only scans
   `renmark_root.rglob("*.md")` for inbound `dependency_refs`; several
   `.renmark/reviews/*.json` files (verified via `rg dependency_refs -g'*.json'`
   during the codex pass) carry `dependency_refs` in JSON frontmatter, not
   markdown. A file referenced only from a JSON artifact could be
   misclassified as unreferenced and become delete-eligible under the safe
   -deletion predicate's "zero inbound refs" condition. **Confirmed real** —
   the bounded blast radius (ephemeral+regenerable+aged types only) limits
   impact, but it's a genuine correctness gap in the reference scan.
